CLASS: B-high
MODEL: opus
ROLE: frontend
WORKTREE: ../persona-onboarding-worktrees/fe-001
BRANCH: claude/fe-001
DEPENDS ON: DESIGN-001 (spec frozen at its merge commit)

## TASK
Create the Next.js app in apps/web and implement the static/interactive shell of every
spec state with a **mock session driver** (no agent service yet): chat transcript +
composer, implicit progress checklist, call offer, phone simulator (ringing/connected/
muted/reconnecting/ended with fake audio levels), Gmail connect card states,
graduation, welcome-back. Build harness/visual (capture + diff) and Playwright setup.

## WHY
Unblocks visual review early and gives FE-002/003 real components to wire to the API.

## SCOPE
apps/web/**, harness/visual/**, root package.json (workspace scripts only).

## SPEC
docs/design/spec.md @ <DESIGN-001 merge sha> + docs/design/mockups/ @ same sha + docs/design/tokens.json.

## READ
- CLAUDE.md; docs/design/spec.md; docs/design/tokens.json
- docs/ARCHITECTURE.md §1, §6 (session driver contract: state snapshot + UI pushes)
- .claude/skills/frontend-design/SKILL.md, .claude/skills/webapp-testing/SKILL.md

## DO NOT READ
- .env*, secrets; Penciled sensitive paths (.env*, transcripts/, data/, demo patients, PHI) + other Penciled repos; never modify penciled-emr; services/agent internals

## REQUIREMENTS
- Next.js (App Router, TypeScript strict). Tokens from tokens.json → CSS variables.
- A `SessionDriver` interface (snapshot, sendText, startCall, endCall, onPush) with a
  `MockSessionDriver` that can put the UI in any spec state via `?state=<name>` (used by
  visual capture) — the real driver comes in FE-002.
- `<meta name="build-sha">` in the layout (design-review gate build identity).
- harness/visual/capture.mjs (Playwright, both viewports, all states) and diff.mjs
  (pixelmatch, masks for timer/captions/waveform) writing .persona-qa/visual/report.json
  and a contact sheet; wire `npm run qa:visual` to real results (no longer PENDING).
- Playwright e2e: mock-driver specs for EC-03 (mic denied fallback UI), EC-29 (decline
  call keeps call button), EC-31 (graduated landing).
