## TASK
Wire the Gmail connect card to Google OAuth in **testing mode**: scopes
`openid email profile` + `gmail.readonly` + `gmail.modify` + `gmail.send`,
`access_type=offline`, `prompt=consent`, `include_granted_scopes=true`. Handle
wrong-account and partial-grant. On success, Next.js callback → server-to-server
`POST /v1/sessions/{id}/gmail` with the verified address (token persistence for
GMAIL-001 may be stubbed/encrypted-placeholder if server store is not ready — document).
Keep MockSessionDriver `?state=` paths for visual/e2e.

## WHY
Gmail connect is half the product demo; reviewers hit the unverified-app screen and must
see connected / error / wrong-account / partial-grant states.

## SCOPE

gmail fill API contract. GMAIL-001 owns encrypted refresh-token store + Gmail API client.
