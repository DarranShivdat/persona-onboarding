## TASK
Implement `agent/obs/langfuse_adapter.py` (`LangfuseTracer`) behind the existing
`agent.obs.Tracer` protocol, and route Pipecat OpenTelemetry spans to Langfuse's
OTLP endpoint when tracing is enabled. Keep `PERSONA_TRACING=noop` the default;
`jsonl` unchanged. Wire turn-level traces (session id, channel, node, flow version,
prompt hash) from the text turn path without changing brain semantics.

OBS-002 dataset gate need real Langfuse traces when keys are present.
