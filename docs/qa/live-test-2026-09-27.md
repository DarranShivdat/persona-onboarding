## Fixed and deployed tonight (agent 56ed4f5, LIVE 11:22pm PT; smoke 7/7; hosted browser call PASS)
1. Production text chat now uses Claude: forced `record_slots` extraction (temperature 0,
   capped tokens) + **reaction-only phrasing** (model writes ≤ 1 short sentence; code appends
   the brain's chosen ask/offer/readback — it can't ask the wrong thing, re-introduce itself or
   skip the question). Privacy/injection answers are fixed policy text. Voice turns never
   make an extra LLM call on the text path.
2. Natural acknowledgements everywhere ("Nice to meet you, Darran.", "Juno. I like it.") — no "Got it: X".
3. Gmail "why" is given once per session; no "type your email in the chat" line on the call.
4. "I want to do more than Gmail" is a need, not a refusal (no instant graduation); added needs
   append ("automating emails and texting my mom").
5. Graduation line: "You're all set, Darran. Juno's first job: text my mom. You can connect Gmail
   from the main screen whenever you like." Post-call chat no longer says "Still left" after graduation.
6. Deploy hardening: the image ships `docs/product-facts.md` (first redeploy crashed on it; fixed
   in 2 min) and a text-LLM init failure degrades to templates instead of taking the API down.
